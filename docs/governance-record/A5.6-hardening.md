# A5.6 — Governance Record Reconciliation and Hardening

A5.6 hardens the A5.5 Governance Record validator without changing the Governance Commons Conformance Report contract (`gc_report_version` 1.0.0) or the Governance Record schema version (1.0.0).

## Validation boundary

Governance Record validation remains two-stage:

1. `GR-SCHEMA-001` performs structural validation against `governance-record.schema.json`.
2. Only schema-valid records enter semantic governance rules.
3. `GR-AUTH-001`, `GR-AUTH-002`, and `GR-HANDOFF-001` evaluate authorization, temporal authority, and handoff completeness.
4. Results are emitted through the existing shared `ConformanceReport` contract.

A schema-invalid record therefore cannot be reclassified as semantically conformant, and semantic failures do not require weakening the JSON Schema to encode every governance rule.

## Hardening decisions

### Authorization

An authorized or completed action requires an active applicable authority. Where approval is explicitly required, its status must be `approved`.

### Temporal authority

Authority is evaluated against the action's `timestamps.occurred_at` rather than the time the record happened to be created. A revoked authority cannot support an action after `revoked_at`. An action occurring before `granted_at` is also rejected. A revoked authority without a valid `revoked_at` is rejected rather than silently accepted.

### Orchestrator handoff

An accepted or completed handoff must carry transfer endpoints, a non-empty delegated authority scope, delegated-by reference, trust-boundary information, and a valid acceptance timestamp. This preserves the distinction between a structurally representable handoff and a governably complete handoff.

## Compatibility

- Governance Record schema remains v1.0.0.
- Conformance Report remains v1.0.0.
- Existing record-type conditionals remain schema-owned.
- Semantic governance rules remain validator-owned.
- No second or embedded conformance-report contract is introduced.
- Existing A5.4 fixtures remain the regression corpus.
